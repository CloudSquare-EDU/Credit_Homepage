# 알려진 제한사항 및 향후 개선사항

## 1. NCP API 제한사항

### 1.1 API를 통한 삭제 미지원 서비스
다음 서비스들은 NCP API를 통한 직접 삭제가 지원되지 않습니다:

| 서비스 | 제한 사항 | 대안 |
|--------|----------|------|
| Object Storage | 버킷 삭제 API 미제공 | Console에서 수동 삭제 |
| Cloud DB | 인스턴스 삭제 API 제한적 | Console에서 수동 삭제 |
| Kubernetes Service | 클러스터 삭제 API 복잡 | Console에서 수동 삭제 |
| Container Registry | 레지스트리 삭제 API 미제공 | Console에서 수동 삭제 |
| AI/ML 서비스 | 대부분 API 미제공 | Console에서 수동 삭제 |

### 1.2 서비스 구독 해지
- NCP는 서비스 구독 자체를 해지하는 API를 제공하지 않습니다
- 리소스를 모두 삭제해도 서비스 구독은 유지됩니다
- 서비스 구독 해지는 NCP Console에서 직접 수행해야 합니다

### 1.3 API Rate Limiting
- NCP API는 초당 요청 수에 제한이 있을 수 있습니다
- 대량의 계정을 동시에 조회/삭제할 때 지연이 발생할 수 있습니다
- 현재 요청 간 100-500ms 딜레이를 적용하고 있습니다

## 2. 보안 관련 제한사항

### 2.1 암호화 키 관리
- `ENCRYPTION_KEY`가 유출되면 모든 저장된 API 키가 노출됩니다
- 키 로테이션 기능이 현재 미구현되어 있습니다
- 키 변경 시 모든 계정의 API 키를 재등록해야 합니다

### 2.2 세션 관리
- JWT 토큰은 클라이언트 localStorage에 저장됩니다
- 토큰 무효화(로그아웃) 후에도 만료 전까지 유효합니다
- Refresh Token 메커니즘이 미구현되어 있습니다

---

## 3. 기능적 제한사항

### 3.1 실시간 동기화
- 리소스 정보는 수동 동기화 또는 스케줄러를 통해서만 업데이트됩니다
- 실시간 변경 감지 기능이 없습니다
- WebSocket 기반 실시간 알림이 미구현되어 있습니다

### 3.2 비용 데이터
- 비용 데이터는 NCP Billing API의 일별 데이터에 의존합니다
- 실시간 비용 조회가 불가능합니다 (보통 1-2일 지연)
- 상세 비용 분석 기능이 제한적입니다

### 3.3 리포트
- 현재 CSV 내보내기만 지원됩니다
- PDF 리포트 생성 기능이 미구현되어 있습니다
- 시각화 차트가 대시보드에만 제한적으로 제공됩니다
